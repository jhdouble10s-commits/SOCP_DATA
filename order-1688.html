1688 주문가공

주문 엑셀에서 문의할 주문을 골라, 판매자별로 정리합니다.

파일은 이 브라우저에서만 처리되며 서버에 업로드되지 않습니다.

01하위 주문번호 확인

下游订单号가 있는 행만 유지

02배송비 기준 적용

메모가 없고 배송비 ≤ 15이면 삭제

03배송비 비율 확인

메모가 없고 비율 < 10%이면 삭제

메모가 있는 행은 2·3단계에서 유지합니다. 비율이 정확히 10%인 행도 유지합니다.

원본 주문 파일을 선택하면 자동으로 가공합니다.

가공 결과

다운로드는 검색과 관계없이 최종 주문 전체를 포함합니다. 중복 판매자를 먼저 모으고, 같은 판매자 안에서는 원본 순서를 유지합니다.

다운로드 파일 구성

하나의 엑셀에 시트 2개가 포함됩니다. 첫 번째 Sheet2는 기존 가공 결과 28열입니다. J열은 배송비 비율, M열은 판매자 채팅 링크, O열은 주문번호를 붙인 가격 조정 요청 문구, P열은 순번입니다. 열 제목은 샘플과 동일하게 유지합니다.

두 번째 Sheet3는 下游订单号가 있는 모든 행을 원본 순서대로 담습니다. 원본 A~Z열과 下游订单号의 27열이며, 구매자 메모 및 배송비 조건은 적용하지 않습니다. 买家留言 열은 포함하지 않습니다.

병합된 빈칸은 채우지 않습니다. 상품 정보는 남은 원본 행의 값을 사용하며 수량을 합산하지 않습니다. 채팅 열은 바로 열 수 있는 링크로 저장됩니다.
